# Screenshots

- `ui-login-current.png` — current Telegram Desktop-style welcome screen. Safe to
  publish; contains no account data.
- All other `ui-*.png` files are historical screenshots from early UI iterations.
  They are kept only because `docs/ui.md` references them; they do not represent
  the current interface.

Do not add screenshots of logged-in chats, profiles, phone numbers, QR login
tokens, or settings account headers. Keep private verification screenshots in the
gitignored `temp/` directory or outside the repository.
